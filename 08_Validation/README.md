# Bài 8: Validation

## Nội dung chính
- Bean Validation API (JSR 380 / Hibernate Validator)
- Các annotation validation: `@NotNull`, `@NotEmpty`, `@NotBlank`, `@Size`, `@Min`, `@Max`, `@Pattern`, `@Email`
- Sử dụng `@Valid`, `BindingResult` để bắt lỗi và hiển thị lỗi trên View
- Tùy biến thông báo lỗi và custom validator
